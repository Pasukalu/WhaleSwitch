## WhaleSwitch 1.4.0

本地管理 Codex CLI、Claude Code 与 OpenCode 的配置。本版加入配置来源与外部变更检测。

- 查看用户级编辑目标和项目内的只读配置候选文件。
- 切回窗口后检测外部编辑。保留草稿，并比较旧值、当前文件值和草稿。
- 合并同一路径的修改，按字段选择冲突值。确认保存前再次验证修订，并为已有文件创建加密快照。
- 已支持配置档案、完整快照恢复、项目技能盘点和连接测试。

WhaleSwitch is a local configuration workbench for Codex CLI, Claude Code, and OpenCode. This build adds config source inspection, external change detection, and field-level draft reconciliation. Existing files are backed up in an encrypted snapshot before replacement.
