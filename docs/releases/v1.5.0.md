## WhaleSwitch 1.5.0

- **按字段恢复快照。** 在 Codex CLI、Claude Code 和 OpenCode 的快照中选择要恢复的设置。应用验证当前修订和快照值，再为现有配置建立加密备份。
- **Windows x64 便携 ZIP。** 解压到可写目录，运行 `WhaleSwitch.exe`。应用数据和界面数据保存在同级的 `WhaleSwitchData`，密钥保存在系统凭据管理器。运行需要 WebView2。
- 在 **设置 → 应用数据** 查看当前数据目录。

Restore selected snapshot fields across Codex CLI, Claude Code, and OpenCode. The Windows x64 portable ZIP runs after extraction, keeps app data beside the executable, and uses the installed WebView2 Runtime and Windows Credential Manager.
