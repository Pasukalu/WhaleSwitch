## WhaleSwitch 1.8.0

- **连接故障诊断。** 区分 DNS、TLS、连接被拒、请求超时、HTTP 鉴权、限流和服务端错误。无效 JSON、模型格式不匹配和读取中断分别提示。
- **排查提示。** 显示阶段、耗时、HTTP 状态、返回模型数及服务建议等待时间。连接测试由用户显式触发。
- **脱敏摘要。** 报告仅包含工具、协议、鉴权模式和结果字段，可直接复制用于故障反馈。

Diagnose DNS, TLS, HTTP, response transfer, and model-list format failures. Each test shows the observed stage and a corresponding check. Copy a redacted summary to share the result.
