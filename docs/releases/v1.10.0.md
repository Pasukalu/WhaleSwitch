## WhaleSwitch 1.10.0

- **固定快照与预览清理**。查看加密数据量并按编号勾选要移除的旧快照。每个配置目标最近五份、固定项和方案备份会保留。
- **本地操作记录**。从快照页查看当前工具的写入、恢复、清理和方案执行结果。可导出仅含时间、工具、动作、状态与快照编号的 JSON。

Pin important configuration snapshots and review which older versions to remove. Browse configuration activity by tool and export the timestamp, tool, action, result, and related snapshot number as JSON.
