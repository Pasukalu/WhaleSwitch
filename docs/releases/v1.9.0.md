## WhaleSwitch 1.9.0

- **技能升级**。并排比较已有技能和本地来源的文本。按文件勾选升级范围，可分别处理 `SKILL.md` 和参考文档。
- **加密备份和恢复**。应用前先保存并验证所选文件的备份。在项目的技能备份列表中预览恢复，后来被改动的文件会显示冲突。恢复也留下可撤销的备份。

Compare an existing project skill with a local source and select exactly which files to upgrade. Review encrypted backups by project, restore files that still match the recorded result, and undo a restore using its own backup.
