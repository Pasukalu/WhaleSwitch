## WhaleSwitch 1.6.0

- **配置方案。** 把 Codex CLI、Claude Code 和 OpenCode 的常用档案保留为一份方案，可导入或导出 JSON。
- **集中预览与独立恢复。** 确认各工具的目标及所选字段。所有待写的已有文件先通过加密快照验证。写入失败会尝试恢复已写文件，并在 **最近执行** 中给出状态和可用快照。
- **锁定构建依赖。** npm 与 Cargo 按仓库内锁文件构建。Windows 任务解压并启动便携应用，检查同级 WebView2 数据目录。

Save a multi-tool plan, check each local target path and field diff, and apply selected settings together. WhaleSwitch verifies all existing-file backups before writing and reports per-file results after a failure or interruption.
