## WhaleSwitch 1.7.0

- **技能基线。** 按项目保存 `SKILL.md` 指纹，重新扫描后核对新增、修改和移除。支持按路径筛选。
- **本地导入。** 确认目标位置，逐份审阅清单与参考文档。发现同名目标就暂停，来源内容变化后需要重新预览。
- **安全写入。** 导入先写并校验参考文档，再写 `SKILL.md`。失败时回滚本次创建且内容一致的文件。

Save a local project baseline, review skill manifest changes, and inspect text files before importing a skill. The importer checks the source and destination again before writing.
