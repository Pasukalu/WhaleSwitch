# WhaleSwitch 架构与安全

## 模块边界

| 模块 | 职责 |
| --- | --- |
| `adapters` | 按工具定位用户级配置，从允许列表解析字段，保留 TOML 和 JSON/JSONC 中的其他内容。 |
| `jsonc` | 解析根对象及对象内的原文范围，支持局部键值替换，无需重新序列化整个文件。 |
| `engine` | 文件修订校验、写入预览、快照、还原、档案应用和导入导出。 |
| `sources` | 用户级文件状态的读取结果，及所选项目固定候选路径的只读盘点。项目报告只返回支持字段名。 |
| `skills` | 盘点所选目录下固定位置的技能入口文件，计算项目基线的变更。 |
| `engine::project_skills` 和 `engine::skill_import` | 保留基线指纹，预览和应用项目技能的导入、升级与恢复。 |
| `storage::skill_backups` | 以项目路径指纹索引升级和恢复记录，使用系统密钥库保护备份内容。 |
| `config-session.ts` | 保存被接受的编辑基线、最近一次检查及草稿，生成外部变更的三栏差异和合并后的草稿。 |
| `storage` | SQLite、跨实例文件锁、系统密钥库和加密快照。 |
| `profiles` | 按工具保存有名称的字段集合，档案记录只管理允许列表中的值。 |
| `plans` | 验证跨工具方案的存储及 JSON 格式，保存可用于恢复的执行记录。 |
| `engine::plan_apply` | 预览每种工具的目标和差异，集中预检与备份，逐文件提交并在失败后补偿。 |
| `portable` | Windows 识别可执行文件旁的空标记，将数据库与 WebView 数据定向到 `WhaleSwitchData`。 |
| `probe` | 目标 URL 规则、密钥作用域和显式触发的模型列表请求。 |
| `probe::transport` | DNS 与 TLS 错误分类、请求期限、HTTP 状态与有界的响应校验。仅向界面返回结构化诊断字段。 |
| `desktop` / `src` | Tauri IPC 和原生选文件窗口，以及 React 界面。 |

适配器允许列表与可移植字段见 [README](../README.md)。Codex 的内置 OpenAI provider 使用 `openai_base_url`。Claude Code 的 URL 来自 `env.ANTHROPIC_BASE_URL`。OpenCode 的模型和默认 Agent 在 V1/V2 中共享，保留版本各自的 provider 配置。

## 写入与恢复

前端发送工具、目标路径、修订标记和字段补丁。后端校验目标路径、体积、编码与文件类型。配置读入后以 SHA-256 校验修订标记。检测到外部写入时拒绝提交旧预览。符号链接和 Windows 重解析点路径被拒绝。

更新已有文件前，先将原始字节通过 XChaCha20-Poly1305 加密写入 SQLite，提交并解密验证。之后创建同目录临时文件，持久化后再次检查修订，再执行原子替换。新文件以禁止覆盖模式创建。替换后的验证失败时，只有在确认当前内容仍是本次写入时才尝试恢复，避免覆盖第三方的新版本。应用锁不会限制第三方 CLI，本地文件系统上的最后检查和替换之间存在短暂竞争窗口。Windows 临时文件继承目标目录的安全属性。

配置档案以追加表保存，可与 0.1 快照数据共存。档案保存读取已核实字段以及用户确认的表单草稿。档案应用重新检查修订标记，经过同一个备份与写入流程。删除档案仅移除档案记录。快照还原会写回完整历史文件，并保护当前文件的字节。

字段级恢复从快照和当前文件读取相同允许列表。确实缺席的键可显式恢复为未设置，存在但无法识别的键被排除。后端在写入锁内重新计算差异并校验所选字段、目标路径和修订，再通过同一个备份和原子替换流程写入选中项。

Windows 便携模式在创建主窗口前选择数据库与 WebView 目录。目录、标记和已知数据库文件接受类型及链接检查。安装版和便携版共用系统应用数据目录的写入锁，操作系统凭据管理器持有密钥。 [便携说明](PORTABLE.md)

## 跨工具配置方案

方案保存最多三个工具的受支持字段。保存时复制各档案的内容，日后改名或删除原档案也能继续使用方案。JSON 文件包含格式版本、名称和按工具分组的字段值。导入时验证体积、字段类型、工具重复项和名称，目标路径在本机预览时解析。

应用时后端在共享写入锁内重算差异，验证成功预览的目标路径、修订和所选值，拒绝多个选项指向同一目标。准备所有临时文件并验证已有文件的加密快照后，记录本轮执行并逐文件原子替换。失败时按逆序检查和恢复已写文件。对于外部改写或需要人工核对的文件，执行结果会标出状态和可用快照。

执行记录存放在 SQLite，含方案名称、工具、目标路径指纹、前后内容修订及快照编号。程序中断后，重新打开方案页时按修订比较未完成的文件并显示状态，具体恢复由用户触发。快照及路径匹配规则与单工具操作一致。

## 配置来源与外部变更

返回桌面窗口或手动扫描时，Tauri 在后台线程重新解析所选 CLI 的用户级目标并检查字节修订。前端以工具、路径和修订标记绑定每个预览。路径或修订变化后关闭旧预览。快照列表根据当前编辑目标查询。

编辑器在没有草稿时自动载入新的文件状态。有草稿时，界面保留基线，列出字段的旧值、最新文件值和草稿。合并只调整内存中的编辑基线和补丁。不同路径或无法读取的目标暂停合并与写入，直至恢复原目标或用户明确放弃草稿。后端在用户确认新预览时仍执行原有修订校验与快照流程。

项目盘点由原生目录选择器授权。后端对七个固定路径逐个应用现有文件类型、链接、体积和解析校验，返回状态及支持字段名。环境覆盖只报告受支持的变量是否已设置。项目扫描不读取 CLI 会话、执行配置、解析外部引用或推断运行时覆盖顺序。

## 项目技能基线、导入与恢复

基线表按规范化项目路径的 SHA-256 索引。记录由保存时间、相对 `SKILL.md` 路径和字节指纹构成。用户刷新时不会移动基线。扫描出现跳过项或达到上限后，只显示已确认的新增和修改。

导入的项目根目录与来源目录由原生选择器保存在后端会话。来源须含带前置元数据区的 UTF-8 `SKILL.md`。最多检查 96 个节点，单文件 128 KiB，合计 512 KiB。参考文件限 `references` 下的 Markdown 和纯文本。脚本、二进制、链接及不安全名称在扩展范围之外。前端以纯文本呈现预览。

提交在共享写入锁内重算来源和目标修订。导入仅创建新技能目录，使用禁止覆盖模式逐文件写入，先验证参考文档，再发布 `SKILL.md`。发生写入错误时逆序清理本次创建且指纹一致的文件。进程中断后目标目录可能保留，下一次导入会提示目标已存在。

已有技能的升级使用同一文本文件范围。后端把所选项目、目标位置、源文件指纹和读取到的目标状态绑定到预览修订，提交时重算修订并验证勾选范围。SQLite 提交加密备份后，后端读回验证备份。写入逐文件暂存、原子替换并验证，失败时逆序还原本次写入且指纹仍一致的文件。进程中断时可用已提交的备份预览恢复。

备份保存勾选文件的原始字节或缺失状态，以及提交预期产生的指纹。恢复检查当前指纹，允许用户选择仍与预期匹配的文件。原先缺失的参考文档可在一致性核对后删除。恢复也建立备份，提供撤销路径。密钥不可用时阻止修改。多文件操作的原子性以单个文件为单位。

## 密钥与网络

API 密钥和快照加密密钥进入操作系统安全存储。恢复快照需要原密钥库条目。桌面后端不会读取浏览器、CLI 登录文件或网页会话。模型列表请求由用户手动触发，API 密钥绑定工具、协议及规范化后的完整请求 URL。禁止重定向、继承代理、URL 凭据、查询和片段。HTTPS 是默认要求，HTTP 与无密钥模式各自限制在回环地址。localhost 强制解析到回环地址。

传输层使用操作系统 DNS 和 Rustls，按可辨识的错误类型定位 DNS、建连、TLS、等候响应、HTTP、读取响应和格式校验。建连期限为 5 秒，整次 HTTP 请求的期限为 12 秒，禁用自动重试。仅对成功响应读取正文，最多接受 1 MiB。最小兼容格式为 `data` 数组及每条记录的非空字符串 `id`。返回数量只统计当前响应。

鉴权或限流诊断依据已观测到的 HTTP 状态。429 或 503 的 `Retry-After` 可转换为秒数提示，后续请求仍由用户触发。前端通过明确字段生成摘要，报告仅包含本地工具、协议、鉴权模式、阶段、结果和数值指标。 [HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110.html#section-10.2.3)

JSON 档案和配置档案仅包含支持字段。原文里自带的凭据留在原配置及加密快照中。接口仅返回有界的安全状态与模型数量，日志不会记录密钥或响应正文。
